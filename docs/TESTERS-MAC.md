# tttlog for Mac (alpha)

## Install
1. Drag **tttlog** onto the **Applications** folder in this window.
2. Open tttlog from Applications.
3. **First launch only:** the app isn't signed with an Apple Developer ID yet, so macOS blocks it
   ("tttlog can't be opened" / "Apple could not verify…"). Click **Done**, then open
   **System Settings ▸ Privacy & Security**, scroll down, and click **Open Anyway** next to tttlog.
   After that it opens normally.

## Updates
tttlog checks GitHub once a day. **Help ▸ Check for updates…** checks right away.
**Update now** downloads the new version, replaces the app, and reopens it. Your logs and settings are kept.

## Where things are
- Logs: `~/Documents/tttlog/`
- Settings, macros, downloaded country file: `~/.tttlog/`
- Version: **Help ▸ About tttlog**. Please include it in bug reports.

Report bugs at https://github.com/n3ttt/tttlog/issues
